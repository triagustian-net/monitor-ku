📖 Cara Setup Bot Telegram
1. Buka Telegram → cari @BotFather
2. Ketik /newbot → ikuti instruksi → dapat Bot Token
3. Cari bot kamu di Telegram → klik Start
4. Buka URL ini di browser:
https://api.telegram.org/botTOKEN/getUpdates
5. Cari angka di "chat":{"id": 123456} → itu Chat ID kamu
6. Paste Token & Chat ID di form atas → klik Test Kirim Pesan
